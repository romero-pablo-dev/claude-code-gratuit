Tu as commenté PROMPT, voilà la ressource de la vidéo : OmniRoute.

Un projet open source qui se met entre Claude Code et les modèles d'IA. Tu gardes l'outil Claude Code que tu connais, et derrière, OmniRoute le branche sur plus de 200 fournisseurs, dont des dizaines gratuits. Quand un quota tombe, il bascule tout seul sur le suivant.

200+fournisseurs d'IA reliés
1,6 Mdtokens gratuits par mois, toutes offres cumulées
95 %de tokens économisés au maximum par la compression
  1. Tu installes OmniRoute, une commande.
  2. Tu branches des fournisseurs gratuits dans son tableau de bord.
  3. Tu lances Claude Code à travers lui, et tu codes sans t'arrêter.

Ce que c'est, en vrai

  • Ce n'est pas le modèle Claude offert. C'est l'outil Claude Code (le terminal, les fichiers, les agents) qui tourne sur d'autres modèles : GLM, DeepSeek, Qwen, Gemini, Kimi… Pour le travail courant ça tient très bien, pour les tâches les plus dures garde Claude.
  • Les 1,6 milliard de tokens sont la somme des offres gratuites de chaque fournisseur. Tu crées toi même tes comptes chez eux, OmniRoute les additionne.
  • Tout tourne sur ta machine. Le projet est sous licence MIT, plus de 75 000 étoiles sur GitHub.
2 minutes

1. Ce qu'il te faut

Node.js en version 22 ou plus, et Claude Code. Vérifie ta version de Node :

node -v

Si tu es sous la version 22, installe la dernière LTS sur nodejs.org. Pas encore Claude Code ?

npm install -g @anthropic-ai/claude-code
1 commande

2. Installer OmniRoute

Installe le, puis lance le. Le tableau de bord s'ouvre sur http://localhost:20128.

npm install -g omniroute
omniroute

Si npm bloque l'installation (npm 11 et plus)

npm install -g --allow-scripts=omniroute,keytar,onnxruntime-node,@parcel/watcher,@swc/core,protobufjs,esbuild omniroute

Les avertissements npm warn ERESOLVE pendant l'installation sont sans gravité. Laisse tourner omniroute dans son terminal, il doit rester ouvert.

5 minutes

3. Brancher les modèles gratuits

Dans le tableau de bord, va dans Providers et ajoute ceux marqués gratuits. Chacun demande un compte chez lui et une clé API. Pour démarrer :

  • OpenRouter : ses modèles :free, une seule clé pour beaucoup de modèles.
  • NVIDIA NIM : GLM, MiniMax, environ 40 requêtes par minute offertes.
  • Z.AI : GLM 4.7 et GLM 4.5 Flash, gratuits.
  • Cloudflare AI : plus de 50 modèles, un quota offert chaque jour.

Ensuite, va dans Endpoints et copie ta clé OmniRoute : c'est elle que Claude Code va utiliser. Plus tu branches de fournisseurs, moins tu tombes à court.

1 commande

4. Lancer Claude Code dessus

Dans un deuxième terminal :

omniroute run claude --model auto

auto choisit le meilleur modèle disponible parmi tes fournisseurs et passe au suivant dès qu'un quota tombe. Pour du code, essaie auto/coding, qui privilégie la qualité.

Ou le configurer une fois pour toutes

omniroute setup-claude

Vérifier que tout marche

curl http://localhost:20128/v1/models -H "Authorization: Bearer TA_CLE_OMNIROUTE"

Tu dois voir la liste des modèles que tu as branchés.

Les deux trucs de la vidéo

La bascule automatique

C'est le modèle auto : quand un fournisseur atteint sa limite ou tombe en panne, OmniRoute envoie la requête suivante au prochain modèle disponible. Ta session continue, tu n'as rien à faire.

La compression des prompts

Activée par défaut. Chaque requête est compressée avant de partir vers le modèle : de 15 à 95 % de tokens en moins selon le contenu. Le code, les liens et les données structurées ne sont jamais touchés.

Bon à savoir

  • Garde ton abonnement Claude à part. Utilise claude normalement tant que tu as du quota, et omniroute run claude quand ta limite tombe. Évite de brancher ton compte Claude Pro ou Max comme fournisseur dans OmniRoute : des utilisateurs ont eu leur compte coupé par Anthropic juste après (voir le signalement).
  • Pas de données sensibles sur les offres gratuites. Certains fournisseurs gratuits peuvent se servir de ce que tu leur envoies. Rien de confidentiel, rien qui concerne tes clients.
